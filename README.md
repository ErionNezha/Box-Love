# 💝 Box-Love

Kuti dashurie 3D rrotulluese — kub i animuar me CSS me zemra në çdo faqe. Fotot personale të origjinalit janë zëvendësuar me ilustrime gjenerike.

## 🚀 Si ta hapësh

Hap `index.html`, kliko **Live Demo** — kubi rrotullohet automatikisht.
